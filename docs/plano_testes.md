# Mini Plano de Testes — BiblioTech

> Preencha este documento no início da atividade, antes de escrever os casos de teste.

## Escopo
RF01, RF02 e RF03.

## Fora do escopo
Interface gráfica, banco de dados, segurança e desempenho.

## Estratégia
- Caixa preta baseada nos requisitos.
- Caixa branca baseada na estrutura do código.
- Testes unitários automatizados com pytest.

## Ambiente
Python + pytest + GitHub.

## Critério de entrada
Código disponível e requisitos definidos.

## Critérios de saída
- requisitos críticos testados;
- testes executados;
- defeitos registrados;
- cobertura >= 90%;
- Pull Request criado.

## Riscos
Tempo limitado da atividade e cobertura incompleta.

## Entregáveis
- casos de teste;
- testes automatizados;
- relatório de cobertura;
- Pull Request.
